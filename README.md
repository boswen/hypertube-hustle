# 🚀 Hypertube Hustle

A fast-paced level-based runner set in the world of industrial chaos and
conveyor-belt ambition.

Built in Unity as part of a long-weekend Game Jam challenge.

---

## 🎮 About the Game

**Hypertube Hustle** is a 2.5D endless runner inspired by factory
automation aesthetics and high-speed traversal.

You were minding your own business when a hypertube malfunction launched
you across the map.\
Your inventory exploded everywhere.\
Now it's time to sprint, dodge, stomp, and survive.

This demo contains:

-   ✅ A fully playable Level 1 vertical slice\
-   🐗 Stompable hog enemies\
-   ⚠️ Obstacle avoidance mechanics\
-   📱 Mobile-ready tap controls\
-   💀 Grounded death system (no floating death animations!)

---

## 🕹 Controls

### Desktop

-   **Space / Click** --- Jump
-   Avoid obstacles
-   Stomp enemies from above

### Mobile

-   **Tap** --- Jump
-   Tap timing matters!

---

## 🎯 Current Demo Scope (v0.1 -- Level 1 Vertical Slice)

-   Core movement & jumping
-   Enemy stomp mechanic
